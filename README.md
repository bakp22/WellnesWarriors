Worked with a team of 4 students to create an app that motivated individuals to keep track of their mental health. Our app's foundation is built on a point-reward system where logging in to the app, writing a journal entry, or logging your mood for the day gives you a specific amount of points for the user to use as they customize the built-in virtual pet: Walter. The app was built with Swift using Xcode and UIKit. Figma was also utilized to design the app's user interface. If our team were able to work on this project in the future we would implement features which include generating a weekly report that comprises of the user's entries so that it can be sent to their physician in order to allow the provider to understand how to better treat the patient. In addition, we would look forward to implementing a notification system whenever a user stops using the platform on a consistent basis (ex: inactive for 5 days) to see if everything is all right with the individual. This project was completed at the Boston Univeristy Welcome Back Hackathon hosted by BU Spark!
